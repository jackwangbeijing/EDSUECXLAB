Experience Manager Assets

Assets & Dynamic Media

The largest slice of the release. Generally available items land now; Limited Availability and Beta items need an opt-in (see section 06).

GA · Authenticity

C2PA metadata on renditions

Asset renditions carry C2PA metadata derived from the original. New JCR properties dam:hasC2PAManifest and dam:isAiGenerated support Gen AI labeling; inspect with any C2PA tool.

GA · Insights

Assets Insights on Analytics 2.0 API

Admin View’s Assets Insights now uses the Adobe Analytics 2.0 API with OAuth server-to-server auth, preserving impressions/clicks data ahead of the Analytics 1.4 API retirement.

GA · Content Hub

On-the-fly Dynamic Media renditions

Generate rendition variations on demand in Content Hub — no need to maintain multiple pre-generated renditions — to speed activation across channels.

GA · Dynamic Media

C2PA in Dynamic Media

Apply C2PA metadata to assets delivered through Dynamic Media with OpenAPI capabilities and Scene7, so viewers can verify origin, edit history, and AI involvement.

Important notices

Plan-ahead: two platform deadlines

These are the items most worth surfacing to customer teams — both carry hard operational impact.

Enforcement begins Sep 14, 2026

Java API deprecations — deployments and updates at risk

Since April 14, 2026, Cloud Manager pipelines using APIs targeted for removal fail at the Code Quality step, blocking deployments until the usage is removed. Starting September 14, 2026, environments still using these deprecated APIs will not receive critical Adobe release updates and fall outside Adobe’s standard performance and availability commitments — meaning no new features or bug fixes, possible stability impact, and increased security exposure.

Preparing for Java 25: runtime upgrade timeline

Java 25 is the next LTS after Java 21, bringing a smaller memory footprint, more efficient GC and faster JVM warm-up, productivity language features, and a modernized cryptographic key-derivation API. Target dates for planning testing and validation:

TimeframeMilestone
Mid-Oct 2026AEM Cloud Service SDK supports the Java 25 runtime; JDK available from the Adobe Software Distribution portal.
Nov 2026Customers encouraged to optionally enable Java 25 in Cloud environments to validate behavior early.
Feb–May 2027Adobe gradually migrates lower environments (RDE, Dev); validate and report issues. Temporary rollback to Java 21 available.
Jun 2027All runtimes (incl. staging & production) migrate to Java 25; Java 21 is decommissioned and no longer supported by the SDK.

AEM still supports compiling customer code with Java 11, 17, and 21, but Adobe recommends building with Java 25 once available to take full advantage of it.
